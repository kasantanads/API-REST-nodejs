# API REST de Gerenciamento de Transações

Este é um projeto simples de API REST para transações financeiras, desenvolvido com foco em performance e boas práticas do ecossistema Node.js.

## 🛠️ Tecnologias Utilizadas

Abaixo estão os principais frameworks, bibliotecas e plugins que compõem esta aplicação:

| Tecnologia | Função Principal |
| :--- | :--- |
| **Fastify** | Servidor web de alto desempenho. |
| **TypeScript** | Linguagem principal, garantindo segurança de tipos e manutenibilidade. |
| **Knex.js** | Query Builder para acesso e manipulação do banco de dados. |
| **Zod** | Validação robusta e tipada dos dados de entrada (schemas). |
| **Vitest** + **Supertest** | Suíte para testes rápidos de unidade e integração (TDD). |
| **@fastify/cookie** | Gerenciamento de cookies para controle de sessão (`sessionId`). |
| **dotenv** | Gerenciamento de variáveis de ambiente. |
